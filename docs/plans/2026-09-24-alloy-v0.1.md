# Alloy v0.1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 产出可安装的 Claude Code 插件 Alloy v0.1：装一个插件 = OpenSpec 流程 + Superpowers 纪律 + CodeGraph 图谱 + RTK/Caveman/Ponytail 省 token。

**Architecture:** 薄壳编排。Claude 本身是编排器，`alloy-orchestrator` skill 是决策说明书；外部 CLI（rtk/codegraph/openspec）由 `/alloy:setup` 按官方开源源安装；Caveman/Ponytail skill 原文内嵌（零依赖）；`doctor.js` 提供跨平台组件检测与降级依据。

**Tech Stack:** Claude Code 插件规范（plugin.json/commands/skills）、Node.js ≥18（`node:test` 单测）、上游官方安装源（npm / GitHub releases，禁止引用本地路径）。

**设计文档:** `docs/specs/2026-09-24-alloy-plugin-design.md`（本计划的唯一需求来源）

**对设计文档的两处实现级细化**（已在设计文档中同步）：
1. 环境检测用单文件 `scripts/doctor.js`（跨平台 + `node:test` 可单测），不用 ps1/sh 两份。
2. 插件不自带 `.mcp.json`：CodeGraph 的 MCP 配置由官方安装器 `codegraph install` 写入用户级配置（带自动放行），避免 codegraph 未装时插件 MCP server 报错噪音。

- [ ] **Step 3: 写 doctor.js 实现**

创建 `scripts/doctor.js`：

```js
#!/usr/bin/env node
'use strict';
// Alloy 组件体检：检测 rtk / openspec / codegraph / superpowers；
// caveman / ponytail 内嵌本插件，恒可用。
// 退出码：0 = 全部可用；1 = 有组件缺失（降级运行）。
const { execSync } = require('child_process');
const fs = require('fs');
const os = require('os');
const path = require('path');

const EXTERNAL_TOOLS = [
  {
    name: 'rtk',
    probes: ['rtk --version', 'rtk version'],
    install:
      'macOS: brew install rtk | Linux: curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/HEAD/install.sh | sh | Windows: 下载 https://github.com/rtk-ai/rtk/releases 的 rtk-x86_64-pc-windows-msvc.zip | 兜底: cargo install --git https://github.com/rtk-ai/rtk',
  },
  {
    name: 'openspec',
    probes: ['openspec --version'],
    install: 'npm i -g @fission-ai/openspec',
  },
  {
    name: 'codegraph',
    probes: ['codegraph version', 'codegraph --version'],
    install: 'npm i -g @colbymchenry/codegraph && codegraph install',
  },
];

function probe(cmd) {
  try {
    const out = execSync(cmd, {
      encoding: 'utf8',
      stdio: ['ignore', 'pipe', 'ignore'],
      timeout: 10000,
    });
    return { ok: true, detail: String(out).trim().split('\n')[0].slice(0, 80) };
  } catch {
    return { ok: false, detail: 'not found' };
  }
}

function detectSuperpowers(homedir = os.homedir()) {
  try {
    const p = path.join(homedir, '.claude', 'plugins', 'installed_plugins.json');
    const data = JSON.parse(fs.readFileSync(p, 'utf8'));
    const plugins = data.plugins || data;
    const ok = Object.keys(plugins).some((k) => k.startsWith('superpowers@'));
    return { ok, detail: ok ? 'plugin installed' : 'plugin not installed' };
  } catch {
    return { ok: false, detail: 'cannot read installed_plugins.json' };
  }
}

function checkAll({ runner = probe, superpowersRunner = detectSuperpowers } = {}) {
  const results = [];
  for (const tool of EXTERNAL_TOOLS) {
    let r = { ok: false, detail: 'not found' };
    for (const p of tool.probes) {
      r = runner(p);
      if (r.ok) break;
    }
    results.push({ name: tool.name, ...r, install: tool.install });
  }
  results.push({
    name: 'superpowers',
    ...superpowersRunner(),
    install: '插件市场安装 superpowers（/plugin marketplace add claude-plugins-official）',
  });
  for (const name of ['caveman', 'ponytail']) {
    results.push({ name, ok: true, detail: 'embedded in alloy', install: 'none' });
  }
  return results;
}

function exitCode(results) {
  return results.every((r) => r.ok) ? 0 : 1;
}

function render(results) {
  const lines = results.map(
    (r) => `${r.ok ? 'ok     ' : 'MISSING'}  ${r.name.padEnd(12)} ${r.detail}`
  );
  const missing = results.filter((r) => !r.ok);
  if (missing.length) {
    lines.push('', 'install hints:');
    for (const m of missing) lines.push(`  ${m.name}: ${m.install}`);
  }
  return lines.join('\n');
}

module.exports = { probe, detectSuperpowers, checkAll, exitCode, render, EXTERNAL_TOOLS };

if (require.main === module) {
  const results = checkAll();
  console.log(render(results));
  process.exit(exitCode(results));
}
```

```markdown
  用于 /alloy:flow，或任何"先探查→再规格→实现→交付"的编码任务。

# Alloy 编排器

按四阶段执行编码任务。每阶段先查组件可用性，按降级表行动。全程遵循 caveman（输出极简）与 ponytail（代码极简）风格。

## 阶段 0：环境探查（每会话一次）

运行 `node "${CLAUDE_PLUGIN_ROOT}/scripts/doctor.js"` 记录各组件 ok/missing。本会话已运行过 /alloy:status 且此后未变环境时，直接复用其结果。

## 阶段 1：explore（上下文）

按序尝试，命中即停：

1. CodeGraph MCP 可用（工具列表含 `codegraph_explore`）→ 用它查询任务涉及的文件与符号。只取符号级结果，不整读大文件。若返回"项目未索引"类提示 → 建议用户跑 `codegraph init`，本次先走第 3 条。
2. CodeGraph CLI 可用（doctor 报 ok）→ `codegraph explore "<任务关键词>"`。
3. 均不可用 → Grep/Glob 自行探索；交付时注明"上下文未建图"。

本阶段及后续 shell 命令，rtk 可用时优先加 rtk 前缀走压缩输出（常用包装：`rtk grep ...`、`rtk git ...`、`rtk test ...`、`rtk ls ...`）。rtk 报错或不支持该命令时，回退原生命令，不重试不纠结。

## 阶段 2：spec（规格）

- openspec 可用（doctor 报 ok）→ 用 openspec 创建变更提案（proposal/spec/tasks），向用户展示摘要并等确认。
- 不可用 → 在 `docs/specs/` 手写 markdown 规格（≤30 行：动机 / 改动点 / 验收标准），等用户确认。
- **规格未经用户确认，不得进入阶段 3。** 用户明确说跳过规格时才可跳过。

## 阶段 3：实现

- 遵循 ponytail：先爬最小阶梯——能复用现有代码吗？标准库有吗？已装依赖能解吗？能一行吗？最后才是最小实现。
- superpowers 可用 → 走其 test-driven-development 技能：测试先行，RED→GREEN→REFACTOR。
- 不可用 → 仍执行同等纪律：先写失败测试 → 最小实现 → 运行验证。测试框架跟项目现状，不新引入。

## 阶段 4：交付

遵循 caveman（full 档）：汇报 ≤10 行，动词开头，必含四项：改了啥 / 测了啥 / 风险 / 下一步。本会话降级过的组件在此注明（如"上下文未建图""规格为手写 markdown"）。

## 降级总表

| 组件 | 检测方式 | 不可用时 |
|---|---|---|
| codegraph | MCP 工具列表含 `codegraph_explore`，或 doctor 报 ok | Grep/Glob 探索，交付注明"未建图" |
| rtk | doctor 报 ok | 原生命令，不加前缀 |
| openspec | doctor 报 ok | `docs/specs/` 手写规格 |
| superpowers | doctor 报 ok | 内置轻量 TDD 纪律（测试先行） |
| caveman / ponytail | 内嵌，恒可用 | 不适用 |
```

```markdown
# /alloy:setup

逐项检测并安装缺失组件。只使用官方开源安装源。每装一项立即回读版本验证；失败给出手动命令兜底并继续下一项，绝不静默、绝不中断。

## 步骤

1. 运行 `node "${CLAUDE_PLUGIN_ROOT}/scripts/doctor.js"`，记下缺失项清单。

2. 对每个缺失项按当前平台安装（装一项验一项）：

   **openspec**（全平台）：
   - 装：`npm i -g @fission-ai/openspec`
   - 验：`openspec --version`
   - 兜底：https://github.com/Fission-AI/OpenSpec

   **codegraph**（全平台）：
   - 装：`npm i -g @colbymchenry/codegraph`
   - 验：`codegraph version`
   - 然后运行 `codegraph install`（官方安装器把 MCP server `codegraph serve --mcp` 写入 Claude Code 用户级配置并设置自动放行）。它可能是交互式命令：若当前环境无法应答 TTY 提示，改为提示用户在终端自行运行 `codegraph install`，不要挂起等待
   - 兜底（打印给用户手动执行）：`npx @colbymchenry/codegraph`（官方交互安装器）

   **rtk**（https://github.com/rtk-ai/rtk）：
```
